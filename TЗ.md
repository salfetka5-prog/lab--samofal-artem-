# Технічне завдання (Сайт з розкидками гранат CS2)

## 1. Вступ
Проєкт являє собою вебсайт для гравців Counter-Strike 2, де зібрані розкидки гранат (smoke, flash, molotov) для різних карт. Користувач може переглядати навчальні матеріали, фільтрувати за картою/типом гранати та додавати власні розкидки.

## 2. Мета і задачі
- **Мета:** надати гравцям CS2 зручний ресурс для вивчення розкидок гранат.
- **Основні задачі:**
  - Реалізувати каталог гранат із сортуванням/фільтрацією.
  - Додати сторінку з інтерактивною картою та точками для розкидок.
  - Реалізувати можливість додавати нові розкидки через форму.
  - Забезпечити адаптивність сайту для ПК та мобільних пристроїв.

## 3. Цільова аудиторія
- Геймери, які хочуть навчитися ефективним розкидкам.  
- Кіберспортсмени, які готуються до турнірів.  
- Стрімери/ютубери, які шукають матеріали для контенту.  
Ключові сценарії:
- Знайти розкидку для конкретної карти (наприклад, Mirage).  
- Подивитися коротке відео/анотацію до розкидки.  
- Додати власну розкидку з описом і скріншотом.  

## 4. Функціональні вимоги
1. **Каталог розкидок** — список із фільтрацією за картою та типом гранати.  
   *Критерій приймання:* при виборі карти Mirage показуються лише її розкидки.  
2. **Інтерактивна карта** — показує точки кидків з описом.  
   *Критерій приймання:* при кліку на точку відкривається опис + медіа.  
3. **Додавання розкидки** — форма з описом, скріншотом/відео та картою.  
   *Критерій приймання:* після додавання розкидка з’являється в каталозі.  

## 5. Нефункціональні вимоги
- Продуктивність: відображення сторінки < 300 мс.  
- Безпека: авторизація для додавання розкидок (OAuth2 через Google).  
- Сумісність: Chrome, Firefox, Edge, Safari.  
- Логування: помилки в консоль + відправка на сервер.  

## 6. Обмеження та припущення
- Фронтенд: Angular + TypeScript.  
- Бекенд: Node.js (NestJS) або Firebase.  
- База даних: Firestore/PostgreSQL.  
- Термін реалізації MVP — 3 тижні.  

## 7. Інтерфейс користувача
- **Головна сторінка:** список карт CS2.  
- **Сторінка карти:** інтерактивна схема з точками кидків.  
- **Форма додавання:** поля для назви, опису, вибору карти, завантаження медіа.  

## 8. Архітектурні рішення
- **Front-end:** Angular, TailwindCSS.  
- **Back-end:** NestJS / Firebase Functions.  
- **БД:** Firestore або PostgreSQL.  
- **CI/CD:** GitHub Actions (build + тестування).  
- **Деплой:** Vercel/Netlify (front), Railway/Render (back).  

## 9. План робіт та етапи
- **Ітерація 1:** базова структура Angular + сторінка з картами.  
- **Ітерація 2:** інтерактивна карта + каталог розкидок.  
- **Реліз 1:** додавання розкидок користувачами + авторизація.  

## 10. Критерії приймання
- Каталог правильно відображає розкидки за картою/типом.  
- Інтерактивна карта працює та показує точки.  
- Додавання розкидки доступне лише після логіну.  
- Тести проходять успішно (unit + integration).
